# Bluemind

잠깐 멈추고, 일상의 소리에 귀 기울여 보세요.

Bluemind는 인스타그램, 틱톡, 유튜브, X에서 콘텐츠를 열기 전에 한 번 선택할 수 있게 하는 한국어 안드로이드 앱입니다. 열람 기록과 설정은 기기에 저장됩니다.

## 사용 방법

1. 첫 실행의 권한 설정에서 **접근성 설정 열기**를 누르고 **Bluemind 콘텐츠 가림**을 켭니다. 다운로드한 APK의 접근성 설정이 잠겨 있으면 **설정 → 앱 → Bluemind → 앱 정보의 메뉴 → 제한된 설정 허용**을 확인합니다.
2. 리밴스드처럼 패키지명이 달라진 앱은 **설정 → 앱 연결**에서 플랫폼별로 설치된 앱을 선택합니다. 자동 감지로 되돌리거나 패키지명을 직접 입력할 수도 있습니다.
3. 앱을 열었을 때 게시물과 영상 위에 빗방울과 **스스로 판단하고 선택하세요**가 표시됩니다. 가림을 누르면 게시물은 그 자리에서 보이고, 영상·쇼츠 카드는 해당 앱의 원래 클릭 동작으로 열립니다.
4. **제한**에서 일일 횟수와 이동 시간창 규칙을 설정합니다. 초기 일일 한도는 50회이며 무제한으로 바꿀 수 있습니다. 일일 한도는 기기의 현지 시각 00:00에 새로 시작합니다. 예를 들어 **3시간에 5회 제한**과 **1시간에 2회 알림**을 함께 적용할 수 있습니다.
5. **오늘**과 **기록**에서 횟수, 열람 시간, 앱별 합계와 일·주 그래프를 볼 수 있습니다. **설정**에서 플로팅 카운터의 표시·크기, 색상, 권한을 바꾸고 홈 위젯을 추가할 수 있습니다.

피드·검색·공유 메시지 등의 미리보기 자동재생은 집계에서 제외합니다. 선택해서 펼친 게시물, 재생이 확인된 쇼츠와 일반 영상은 각각 1회로 기록됩니다. 승인된 쇼츠 뷰어에서 같은 뷰어의 네이티브 스크롤이 확인되면 새 쇼츠를 다시 가리지 않습니다. 한도를 채운 항목은 계속 볼 수 있으며 다음 항목부터 가립니다. 틱톡 사진·텍스트 게시물과 유튜브 커뮤니티 게시물도 개별적으로 가립니다.

## 접근성 및 Android 16

Bluemind는 시스템이 연결하는 접근성 서비스를 사용합니다. **설정 → 작동 상태**에서 접근성 연결, 마지막 서비스 응답, 배터리 최적화·백그라운드 제한, 알림 권한, 최근 앱 프로세스 종료 사유를 확인할 수 있습니다. 설정을 빠뜨렸다면 여기서 다시 여세요. 알림 권한은 규칙 알림에 필요합니다. 접근성 권한으로 가림과 플로팅 카운터를 띄웁니다.

대상 앱이 접근성에 내보내는 뷰 구조와 재생 상태로 감지합니다. Android 14 이상에서는 이미 연 플레이어에 재생 상태나 진행 위치가 표시되지 않을 때 화면의 움직임도 확인합니다. 이 방식은 빠르게 넘긴 영상, 정지 화면이 긴 영상, 보안 창, 다른 뷰 구조를 쓰는 앱 버전에서 감지를 놓칠 수 있습니다. 가림은 시각적으로만 적용되므로 해당 앱의 미디어 재생이나 오디오를 정지시키는 기능과는 다릅니다.

시스템이 연결을 다시 맺으면 저장된 설정과 기록을 읽어 감지를 재개합니다. Android의 강제 종료, 접근성 해제, 제조사 절전 정책이 적용되면 사용자가 앱을 다시 열거나 권한을 확인해야 할 수 있습니다.

## 빌드 및 확인

Android SDK Platform 36과 JDK 17 이상이 필요합니다. 설치 가능한 디버그 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

검증한 동작과 기기에서 확인이 더 필요한 항목은 [요구사항 2차 검증](docs/verification.md)에 기록합니다.
